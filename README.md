# FarMeter Dashboard 🌱

FarMeter Dashboard is the web-based management panel for the **FarMeter waste collection platform**.

It is designed to provide a centralized interface for managing and monitoring waste collection operations, connecting the activities of suppliers and collectors in one place.

## Purpose

The dashboard is intended for two main roles:

- **Manager:** Monitor daily waste collection operations, track pickup requests, and manage supplier and collector activity.
- **Admin:** Oversee the platform and manage administrative operations.

## Main Functions

- Monitor waste pickup requests and their statuses.
- View supplier and collector information.
- Track waste types, estimated weights, and collection details.
- View collection activity and operational statistics.
- Provide separate access for managers and administrators.

## Technology

Built using React, TypeScript, Vite, and Supabase, with React Router for navigation and Recharts for data visualization.
